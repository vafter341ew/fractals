## IFS Fractal Studio

This repository contains a standalone browser applet for exploring two-dimensional affine iterated function systems.

Open `index.html` directly in a browser or host the repository with GitHub Pages. The app has no server, package installation, or CDN dependency.

Features include:

- Three transformations by default
- Add and remove transformations
- Editable affine coefficients for every transformation
- Per-transformation probability weights
- Sierpinski, Barnsley Fern, and dragon-like presets
- Seeded random rendering
- Live transformation distribution statistics
- PNG export
- JSON configuration copying
- Paste configurations from JSON
- Mouse-wheel zoom and drag-to-pan controls
